# Inkstone MDX v0.1.0

First public release of the local-first MDX workspace, under the MIT license.

## Features

- Markdown/MDX editing with syntax highlighting, search, undo/redo and source/split/preview layouts.
- Complete previews up to the 5 MiB source limit, including React components and expressions.
- Rust/WASM compilation with an indexed Markdown parser; compatibility fallback where required.
- Trusted desktop projects with local components and installed browser-compatible npm dependencies.
- Local file save/copy, recovery drafts, Chinese/English interface and Chinese input support.

## Downloads

- macOS Apple Silicon (arm64): DMG or ZIP.
- macOS Intel (x64): DMG or ZIP.
- Windows x64: NSIS installer (.exe).
- Linux x64: AppImage or Debian package (.deb).
- SHA256SUMS.txt provides checksums; BUILD-MANIFEST.json records the exact source commit and build provenance.

## Validation and performance

All release binaries are built from the tagged source commit. Native and packaged-app interaction tests run on their matching operating system and architecture. Publication is gated on the same commit's Verify and Desktop workflows. Full-document rendering, tail components, subsequent edits, sandbox restrictions and save/recovery are covered.

An earlier integrated production build rendered the complete 5,234,634-byte / 303,462-line rich fixture (455,193 DOM elements) in 13.741 seconds from compilation start to React readiness. This is a single Linux CI observation, not a latency guarantee. A separate controlled three-run A/B reduced median total preview readiness from 43.2744 to 13.1529 seconds with identical generated JavaScript. The 5 MiB limit is a guardrail, not a promise of interactive speed on every document or device.

## Known limitations

- Desktop binaries are unsigned; macOS builds are not notarized. OS trust warnings are expected. Do not disable OS security globally. Verify the source and checksums, or build from source if your organization's policy requires signing.
- One earlier Linux CI run produced a blank Electron window and timed out waiting for preview. The cause was not established; an unchanged rerun and other Linux runs passed. This is disclosed as an unresolved intermittent observation, not claimed fixed.
- MDX executes JavaScript. Only open trusted documents/projects. The sandbox restricts capabilities but cannot guarantee CPU/memory isolation; loops and large DOM trees can freeze or crash the app.
- Recovery drafts are local plaintext, best-effort recovery, not durable backups. File conflict checks are not OS-level locks.
- No auto-updater is included. No accounts, telemetry service or cloud document storage are required.
