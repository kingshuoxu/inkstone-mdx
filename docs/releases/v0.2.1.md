# Inkstone MDX v0.2.1

## 工作区改进 / Workspace improvements

- 精简顶部工具栏，让源码和预览有更多空间。 / A more compact toolbar leaves more room for writing and previewing.
- 分栏可拖动，也支持键盘调整：方向键微调，Shift + 方向键快速调节，Enter 居中。拖动时按 Esc 可恢复原来的比例。 / Resize the split with a pointer or arrow keys. Hold Shift for larger steps, press Enter to center, or press Esc during a drag to restore the original split.
- 窄窗口默认显示源码，可随时切到预览或分栏，帮助入口始终可用。 / Narrow windows open in source view, with split, preview, and help still accessible.

## 更新与下载 / Update and download

- v0.2.0：在桌面端选择「帮助 → 检查更新」，下载后手动安装。 / From v0.2.0, use **Help → Check for updates**, then install the downloaded package manually.
- v0.1.0：从下方 Assets 下载并手动安装。 / From v0.1.0, download and install a package from **Assets** below.
- macOS（Apple Silicon / Intel）：DMG 或 ZIP；Windows x64：EXE；Linux x64：AppImage 或 DEB。
- 安装包未签名，macOS 版本未公证。可用 `SHA256SUMS.txt` 校验文件完整性，`BUILD-MANIFEST.json` 记录构建来源。 / Packages are unsigned and macOS builds are not notarized. Use `SHA256SUMS.txt` to verify file integrity and `BUILD-MANIFEST.json` to check build provenance.
