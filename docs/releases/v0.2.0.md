# Inkstone MDX v0.2.0

## New in this release

- Check for stable GitHub releases from the desktop Help menu.
- Download the matching installer with a save-location choice, size limits, SHA-256 integrity verification and cancellation. Failed downloads preserve existing files.
- Open this GitHub repository or a new Issue from the desktop Help menu or browser help dialog, in English or Chinese. No document contents, paths or logs are attached automatically.

## Updating

Users on v0.1.0 must download and install v0.2.0 manually once. Subsequent versions can be checked and downloaded from Help. Installation remains manual: the app does not silently install updates, restart itself or poll in the background.

## Downloads and validation

macOS Apple Silicon and Intel: DMG/ZIP. Windows x64: EXE. Linux x64: AppImage/DEB. SHA256SUMS.txt and BUILD-MANIFEST.json record file integrity, exact source commit and build provenance.

Release builds run native and packaged-app interaction tests on each matching platform/architecture. Publication requires both Verify and Desktop workflows to pass on the exact release commit. The release publisher downloads the uploaded assets again and checks all recorded checksums before making the release public.

## Known limitations

- Binaries remain unsigned and macOS builds are not notarized. SHA-256 checks detect file corruption, not publisher authenticity. Do not disable OS security globally.
- A prior Linux CI run showed an unexplained blank Electron window; subsequent unchanged reruns passed. This intermittent observation is not claimed fixed.
- MDX executes JavaScript. Open only trusted documents/projects; CPU or memory exhaustion can still freeze the app.
- Recovery drafts are local plaintext, best-effort recovery, not durable backups.
- Issue submission is performed by the user on GitHub; avoid including private documents or sensitive logs.
